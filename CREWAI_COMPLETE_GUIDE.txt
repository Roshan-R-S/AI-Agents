3. BASIC AGENTS
================================================================================

WHAT IS AN AGENT?
─────────────────────────────────────────────────────────────────────────────
An agent is:
- AI entity with a role (e.g., "Research Expert")
- Has a goal (e.g., "Find accurate information")
- Has a backstory (personality/expertise)
- Can use tools (optional)
- Can remember conversations (optional)

ANATOMY OF AN AGENT
─────────────────────────────────────────────────────────────────────────────
Agent(
    role="Research Expert",           # What the agent is
    goal="Find information",          # What it tries to do
    backstory="You are thorough",     # Agent personality
    llm=llm,                          # Which AI model to use
    memory=False,                     # Remember past (⚠️ use mistral only)
    tools=[],                         # Functions agent can use (⚠️ use mistral only)
    verbose=True                      # Show what agent is thinking
)

AGENT BEST PRACTICES
─────────────────────────────────────────────────────────────────────────────
✅ Specific role (not "AI Assistant")
✅ Clear goal (not "help with stuff")
✅ Detailed backstory (sets expertise level)
✅ Use mistral model (most compatible)
✅ Test with verbose=True first
✅ Use allow_delegation=False (for local models)

4. MULTI-AGENT SYSTEMS
================================================================================

WHY USE MULTIPLE AGENTS?
─────────────────────────────────────────────────────────────────────────────
✅ Different agents are better at different tasks
✅ One agent reviews another's work
✅ Agents collaborate to improve output
✅ More complex problems become manageable

COMMON PATTERNS
─────────────────────────────────────────────────────────────────────────────

Pattern 1: Sequential (One → Two → Three)
Writer → Editor → Publisher
Each gets output from previous, improves it, passes to next

Pattern 2: Parallel (Multiple at same time)
Agent A ─┐
Agent B ├→ Coordinator → Output
Agent C ─┘
All run together, then one combines results

Pattern 3: Hierarchical (Manager structure)
First Line Support
    ↓
    Specialist
    ↓
    Manager
    ↓
Output

CREW DEFINITION
─────────────────────────────────────────────────────────────────────────────
crew = Crew(
    agents=[agent1, agent2, agent3],     # All agents
    tasks=[task1, task2, task3],         # All tasks in order
    memory=False,                        # Crew memory
    verbose=True                         # Show progress
)

result = crew.kickoff()                  # Run the crew
print(result)                            # See results

5. ADVANCED FEATURES
================================================================================

AGENT PROPERTIES DETAILED
─────────────────────────────────────────────────────────────────────────────

allow_delegation (Default: True)
- If True, agent can ask other agents for help
- Set to False for local models (mistral)

memory (Default: False)
- If True, agent remembers past conversations
- ⚠️ Only works with mistral model on local
- Requires OpenAI for memory analysis with other models

tools (Default: [])
- List of functions agent can call
- ⚠️ Only mistral supports tools reliably
- Keep to 3-5 max (too many confuses agent)

verbose (Default: False)
- If True, show agent thinking process
- Useful for debugging
- Slow down execution slightly

TASK PROPERTIES DETAILED
─────────────────────────────────────────────────────────────────────────────

Task(
    description="What to do",
    expected_output="What you want back",
    agent=agent_name,
    async_execution=False,              # True for parallel, False for sequential
)

CREW PROPERTIES DETAILED
─────────────────────────────────────────────────────────────────────────────

Crew(
    agents=[],                          # List of agents
    tasks=[],                           # List of tasks (IN ORDER)
    memory=False,                       # Crew memory
    verbose=True,                       # Show progress
    max_rpm=None,                       # Rate limiting
)

⭐ TEMPLATE 5: FASTAPI DEPLOYMENT
─────────────────────────────────────────────────────────────────────────────
from fastapi import FastAPI
from pydantic import BaseModel
from crewai import Agent, Task, Crew
from crewai.llm import LLM
from dotenv import load_dotenv

load_dotenv()

app = FastAPI()
llm = LLM(model="ollama/mistral", base_url="http://localhost:11434")

class Request(BaseModel):
    topic: str

@app.post("/api/generate-content")
def generate_content(request: Request):
    agent = Agent(
        role="Content Creator",
        goal="Create content",
        backstory="Expert creator",
        llm=llm
    )
    
    task = Task(
        description=f"Create content about: {request.topic}",
        expected_output="Content",
        agent=agent
    )
    
    crew = Crew(agents=[agent], tasks=[task])
    result = crew.kickoff()
    
    return {"result": str(result)}

@app.get("/")
def health():
    return {"status": "API is running!"}

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8000)

9. TROUBLESHOOTING GUIDE
================================================================================

❌ ERROR: "ModuleNotFoundError: No module named 'crewai'"
──────────────────────────────────────────────────────────────────────────────
CAUSE: CrewAI not installed or virtual environment not activated

SOLUTIONS:
1. Activate virtual environment: venv\Scripts\activate
2. Install: pip install crewai crewai-tools python-dotenv
3. Verify: pip list | findstr crewai


❌ ERROR: "OpenAI API key required"
──────────────────────────────────────────────────────────────────────────────
CAUSE: Using memory=True with local models (mistral tries to use OpenAI for memory)

SOLUTIONS:
1. Remove memory=True from Agent
2. Or set memory=False
3. Use: Agent(role="...", goal="...", backstory="...", llm=llm)


❌ ERROR: "tool not supported" or "Tool error"
──────────────────────────────────────────────────────────────────────────────
CAUSE: Using wrong model (neural-chat doesn't support tools)

SOLUTIONS:
1. Change to mistral: llm = LLM(model="ollama/mistral", ...)
2. Don't use tools with neural-chat
3. Test without tools first


❌ ERROR: "No suitable Python runtime found"
──────────────────────────────────────────────────────────────────────────────
CAUSE: Python 3.14 is too new, need 3.10 or 3.11

SOLUTIONS:
1. Download Python 3.10 from python.org
2. Install it separately
3. Use: py -3.10 -m venv venv
4. Activate and try again


❌ PROBLEM: Script takes 30-50 seconds per agent
──────────────────────────────────────────────────────────────────────────────
CAUSE: Local CPU is slow, Mistral is large model

SOLUTIONS:
1. That's normal for local models! ✓
2. To speed up:
   a) Get NVIDIA GPU (10x faster)
   b) Use smaller model: ollama/neural-chat (faster but less smart)
   c) Use cloud LLM: OpenAI ($0.03 per 1K tokens) or Claude


❌ PROBLEM: Agent produces poor quality output
──────────────────────────────────────────────────────────────────────────────
CAUSE: Vague description or bad backstory

SOLUTIONS:
1. Make description more specific (not "find info", say "find 5 specific facts")
2. Add better backstory (expertise level, experience)
3. Use mistral instead of neural-chat
4. Reduce number of agents (too many confuses workflow)
5. Add more examples in description


❌ ERROR: ".env file not found"
──────────────────────────────────────────────────────────────────────────────
CAUSE: .env file missing or wrong location

SOLUTIONS:
1. Create .env in project root (same folder as agent.py)
2. Add: ANTHROPIC_API_KEY=sk-ant-v7-xxxxx
3. Save file (Ctrl+S in notepad)
4. Restart Python script


❌ ERROR: "Pydantic validation error"
──────────────────────────────────────────────────────────────────────────────
CAUSE: Agent/Task configuration is wrong

SOLUTIONS:
1. Check indentation (Python is picky!)
2. Remove memory=True if using local models
3. Use correct imports: from crewai import Agent, Task, Crew
4. Set: allow_delegation=False for local models


❌ ERROR: "Streamlit won't start"
──────────────────────────────────────────────────────────────────────────────
CAUSE: Streamlit not installed or port busy

SOLUTIONS:
1. Install: pip install streamlit
2. Run: streamlit run code_dashboard.py
3. If port busy: streamlit run code_dashboard.py --server.port 8501
4. Check console for errors


❌ ERROR: "FastAPI won't start"
──────────────────────────────────────────────────────────────────────────────
CAUSE: FastAPI not installed or port busy

SOLUTIONS:
1. Install: pip install fastapi uvicorn
2. Run: python api_server.py
3. Visit: http://localhost:8000/docs
4. If port busy, change port in code: uvicorn.run(app, port=8001)


❌ PROBLEM: "Ollama is running but agents still slow"
──────────────────────────────────────────────────────────────────────────────
CAUSE: Using CPU instead of GPU

SOLUTIONS:
1. Check if you have NVIDIA GPU: nvidia-smi
2. If yes, update Ollama (it auto-detects GPU)
3. Restart Ollama app
4. Try again

================================================================================
KEY CONCEPTS SUMMARY
================================================================================

AGENT
- AI entity with role, goal, backstory
- Can have tools (functions to call)
- Can have memory (remembers past)
- Uses LLM (language model) to think

TASK
- What you want agent to do
- Has description (detailed instructions)
- Has expected_output (what you want back)
- Assigned to one agent

CREW
- Team of agents
- Executes tasks in order (sequential)
- Agents pass outputs to next agent
- Can have memory too

LLM (Language Model)
- The AI brain (mistral, gpt-4, claude, etc.)
- Takes text input, produces text output
- Local (slow, free) vs Cloud (fast, $$)

WORKFLOW
- Order agents and tasks execute
- Sequential: One → Two → Three
- Each agent builds on previous work

LATENCY
- Time for agent to complete task
- Local: 30-50s per agent (slow)
- Cloud: 2-5s per agent (fast)
- ≈ LLM processing + network overhead
